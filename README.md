Forecasts how many people watch Grand Theft Auto VI live on Twitch in each hour of its release day, as five quantiles an hour, from the first hour's print. It fits a log-ratio regression at runtime from past rolling-midnight console launches, so a small first hour predicts a big ramp into the US evening and a huge first hour predicts a nearly flat day.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
